# Состояние серверной интеграции

Необходимо сверить и реализовать интеграцию по фактическому серверному исходному коду. Не считать перечисленное ниже существующим контрактом — это перечень пользовательских сценариев, которые требуется сопоставить с API:

- получение категорий и подразделов;
- получение стран и городов;
- список объявлений и фильтры;
- карточка объявления;
- получение разрешения/токена на публикацию, если это предусмотрено API;
- публикация объявления и фотографий;
- отправка жалобы.

До сверки не фиксировать имена PHP-файлов, URL, HTTP-методы, параметры, JSON-структуры и коды ошибок.
