# ForLove Android

Приложение ForLove для Android на Kotlin и Jetpack Compose.

## Реализовано

- Нативный главный экран с карточками реальных объявлений.
- Карточки и фильтры извлекаются из фактически отрисованной страницы 4lov.ru; фиктивные объявления и локальный каталог категорий не используются.
- Нативный поиск по загруженным объявлениям и фильтрация по категориям сайта.
- Переход к настоящей странице объявления и форме публикации сайта сохраняет действующую серверную логику, модерацию, выбор города и загрузку фотографий.
- Нижняя навигация: «Главная», «Поиск», «Разместить».
- Фирменный знак 4♡.

## Что пока остаётся веб-экраном

Детальная страница объявления и форма публикации пока открываются внутри WebView. Отдельный подтверждённый публичный API для этих операций не найден, поэтому приложение не имитирует серверные ответы и не создаёт фальшивые объявления.

Категории берутся из фильтров, которые сайт реально отдаёт на главной странице. Для появления новой категории сайт должен включить её в свою разметку.

## Ограничения проекта

- Публикация только в России и Беларуси — проверка остаётся на стороне сайта.
- Нет обязательной регистрации, личных кабинетов, внутренних чатов, лайков, рейтингов или подписок.

## Сборка

JDK 17, Gradle 8.11.1, Android SDK Platform 35.

```bash
gradle assembleDebug
```
