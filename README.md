# 4LOV Android

Android-приложение 4LOV (ForLove), Kotlin. В этой версии приложение открывает **живой сайт 4lov.ru** внутри нативной оболочки Android.

## Как работает

- Главная, список и карточки объявлений загружаются непосредственно с сайта 4lov.ru.
- Разделы и подразделы берутся из актуальной серверной версии сайта, а не из захардкоженного списка приложения.
- Публикация открывает настоящий `/create.php`: форма, категории, поиск города, загрузка 1–5 фотографий, проверка контактов и отправка на модерацию обрабатываются существующим PHP-кодом сайта.
- Внизу приложения есть навигация «Главная», «Поиск», «Разместить».
- Для выбора фотографий используется системный Android picker.
- Демонстрационные объявления и локальная подмена категорий не используются.

## Важные ограничения

Это гибридная оболочка над мобильной версией сайта, а не отдельная нативная реализация каждого экрана. Поэтому функциональность объявлений и публикации зависит от доступности и актуальности самого 4lov.ru. Категория «ВМЕСТЕ» появится в приложении тогда, когда она существует и активна в серверной базе сайта; приложение не создаёт её локально и не может добавить её в базу самостоятельно.

## Сборка

Требуется JDK 17, Gradle 8.11.1 и Android SDK Platform 35.

```bash
gradle assembleDebug
```

APK собирается GitHub Actions при создании Pull Request в `main` или вручную через workflow_dispatch.

## География и продуктовые ограничения

- Только Россия и Беларусь — ограничения публикации задаются сервером сайта.
- Без обязательной регистрации, личных кабинетов, внутренних чатов, лайков, рейтингов и подписок.
- Фирменный знак: `4♡`.
